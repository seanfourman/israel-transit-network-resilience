# מקורות הדאטה

## GTFS — General Transit Feed Specification

GTFS הוא פורמט סטנדרטי בינלאומי לנתוני תחבורה ציבורית.
הוא מורכב מקבצי CSV שמתארים את הרשת בצורה שלמה.

### מקור הדאטה

הדאטה מגיע מתחבורה ציבורית ישראלית.
קבצי GTFS נמצאים בתיקייה: `israel-public-transportation/`

---

## תיאור קבצי GTFS

### stops.txt — תחנות
```
stop_id      - מזהה ייחודי לתחנה
stop_name    - שם התחנה בעברית ואנגלית
stop_lat     - קו רוחב (latitude)
stop_lon     - קו אורך (longitude)
parent_station - מזהה תחנת אב (אם קיים)
stop_desc    - תיאור נוסף (לעיתים שם העיר)
```

**חשיבות למחקר:** תחנות = צמתים בגרף. כל stop_id יהפוך לnode.

---

### routes.txt — קווים
```
route_id     - מזהה ייחודי לקו
agency_id    - מזהה המפעיל
route_short_name - מספר הקו (למשל "51")
route_long_name  - שם מלא (למשל "תל אביב - ירושלים")
route_type   - סוג (0=רכבת קלה, 1=מטרו, 2=רכבת, 3=אוטובוס)
```

**חשיבות למחקר:** route_type מאפשר להבדיל בין סוגי תחבורה ולנתח כל אחד בנפרד.

---

### trips.txt — נסיעות
```
trip_id      - מזהה ייחודי לנסיעה
route_id     - הקו שאליו שייכת הנסיעה
service_id   - מזהה לוח הזמנים (קישור ל-calendar.txt)
direction_id - כיוון הנסיעה (0 או 1)
shape_id     - קישור לנתוני צורת המסלול
```

**חשיבות למחקר:** כל trip מגדיר רצף של תחנות — זה מה שיוצר קשתות בגרף.

---

### stop_times.txt — זמני עצירה
```
trip_id        - הנסיעה
stop_id        - התחנה
stop_sequence  - מיקום התחנה ברצף הנסיעה
arrival_time   - זמן הגעה
departure_time - זמן יציאה
```

**חשיבות למחקר:** זהו הקובץ המרכזי לבניית הגרף.
כל זוג עוקב (stop_sequence[i], stop_sequence[i+1]) של אותה trip יוצר קשת.

---

### calendar.txt — לוח זמנים
```
service_id - מזהה שירות
monday, tuesday, ..., sunday - האם פעיל ביום זה (0/1)
start_date, end_date - תקופת פעילות
```

**חשיבות למחקר:** משמש לסנן trips שאינם פעילים (לא אמורים לרוץ).

---

### agency.txt — מפעילים
```
agency_id   - מזהה מפעיל
agency_name - שם המפעיל (Egged, Dan, Metropoline וכו')
```

**חשיבות למחקר:** מאפשר השוואת קהילות לפי מפעיל.

---

## הערות חשובות על הדאטה

1. **stop_times.txt הוא הקובץ הגדול ביותר** — עשרות מיליוני שורות. ייתכן שנצטרך לסנן לתת-קבוצה.

2. **parent_station** — תחנות מטרו/רכבת לעיתים מחולקות לרציפים. יש להחליט האם לאחד אותן.

3. **שעות מעל 24:00** — GTFS מאפשר זמנים כמו 25:30 (שעה אחת וחצי אחרי חצות). חשוב לטפל בזה.

4. **route_type** — סוג הקו קובע את אופי הקשת. כדאי לבדוק האם לכלול כל הסוגים.
