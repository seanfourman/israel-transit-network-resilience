## שיטת שיוך — גיאוגרפי (ראשי)

שיוך לפי קואורדינטות lat/lon מתוך stops.txt:

```python
def assign_region(lat, lon):
    # ירושלים — לפי קואורדינטות ספציפיות
    if 31.70 <= lat <= 31.90 and 34.95 <= lon <= 35.30:
        return "ירושלים"
    # צפון
    elif lat > 32.70:
        return "צפון"
    # מרכז
    elif lat >= 31.55:
        return "מרכז"
    # דרום
    else:
        return "דרום"
```

## שיטת שיוך — לפי מטרופולין (משלים)

```python
import math

metro_centers = {
    "תל אביב": (32.0853, 34.7818),
    "חיפה":    (32.7940, 34.9896),
    "ירושלים": (31.7683, 35.2137),
    "באר שבע": (31.2518, 34.7913),
}

def assign_metro(lat, lon, radius_km=25):
    for city, (clat, clon) in metro_centers.items():
        dist = haversine(lat, lon, clat, clon)
        if dist <= radius_km:
            return city
    return "פריפריה"
```

## גבולות האזורים — תיאורי

### צפון
- גליל, כרמל, עמק יזרעאל
- ערים מרכזיות: חיפה, נצרת, עפולה, טבריה, נהריה, קריית שמונה

### מרכז
- גוש דן, שרון, שפלה
- ערים מרכזיות: תל אביב, רמת גן, פתח תקווה, ראשון לציון, הרצליה, נתניה

### ירושלים
- ירושלים ויישובים קרובים
- ערים מרכזיות: ירושלים, בית שמש, מעלה אדומים

### דרום
- נגב, ערבה
- ערים מרכזיות: באר שבע, אשדוד, אשקלון, אילת

| שאלה | מדד |
