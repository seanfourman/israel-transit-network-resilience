# שלב 00 — סקירת הפרויקט והגדרת שאלת המחקר

## מה המטרה של החלק הזה?

להגדיר בצורה ברורה ומדויקת את שאלת המחקר, את שאלות המשנה, ואת הרצף הלוגי של כל הפרויקט.
זהו ה"כותרת" של המחקר — בלי הגדרה טובה של השאלה, כל שלב אחר עלול ללכת לאיבוד.

## למה אנחנו עושים את זה?

מחקר טוב מתחיל בשאלה ברורה. אם נתחיל לנתח גרף בלי לדעת מה אנחנו מחפשים,
נסיים עם הרבה מספרים ואין תשובה. הגדרת השאלה כאן מבטיחה שכל שלב עונה על משהו ספציפי.

## קלט

אין קלט טכני. זהו שלב הגדרה בלבד.

## פלט

- `research_question.md` — שאלת המחקר הראשית ושאלות המשנה
- `project_flow.md` — תרשים הזרימה של כל הפרויקט
- `final_deliverables.md` — רשימת כל מה שצריך לייצר בסוף הפרויקט

## איך זה מקדם את שאלת המחקר?

ישירות — זה השלב שבו שאלת המחקר נוצרת. כל שאר השלבים יצטטו ויסתמכו על ההגדרות שכאן.

## קבצים בחלק הזה

| קובץ | תוכן |
|------|------|
| `README.md` | המסמך הנוכחי |
| `research_question.md` | שאלות המחקר |
| `project_flow.md` | רצף השלבים |
| `final_deliverables.md` | תוצרים נדרשים |

## מה צריך להופיע בדוח הסופי?

- פסקת מבוא עם שאלת המחקר
- הסבר למה נבחרה התחבורה הציבורית כנושא
- הסבר למה גישת הגרף מתאימה לנושא זה
