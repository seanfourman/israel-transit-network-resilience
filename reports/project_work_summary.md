# Project Work Summary

This report summarizes what the project does, which course material it uses, how each part was implemented, and what result it gives or will give after the full GTFS data is restored.

| Short title | Short description | Lecture material used | How we did it | Result / output |
|---|---|---|---|---|
| Transit graph model | Model Israel public transportation as a graph. | Graph definitions, directed/undirected graphs, weighted edges, network representation. | Stops are nodes. Consecutive stops in each GTFS trip become directed edges. Edge frequency is stored as weight. An undirected copy is used for structural analysis. | Existing run built 30,466 active stops, 51,999 directed edges, and 51,772 undirected edges. |
| Connectivity summary | Measure how connected the national transit graph is. | Connected components, weak/strong connectivity, giant component. | Compute connected components on the undirected graph and weak/strong components on the directed graph. | Largest undirected component has 30,237 stops, about 99.25% of active stops. |
| Degree and weighted degree | Find locally important and high-service stops. | Degree centrality, weighted graphs. | Compute degree and weighted degree, where weighted degree counts scheduled segment frequency. | Top weighted stop in existing output is Azrieli / Menachem Begin with weighted degree 21,396. |
| PageRank | Rank stops by directed flow importance. | Spectral centrality, PageRank, random walks. | Run weighted PageRank on the directed stop graph using edge frequency. | Produces `top_pagerank_stops.csv`; useful for stops that receive flow from important predecessor stops. |
| Approximate betweenness | Find bottleneck and transfer stops. | Shortest paths, betweenness centrality, path-based centrality. | Run sampled betweenness on the largest connected component because exact all-pairs betweenness is too expensive. | Produces `top_approx_betweenness_stops.csv`; highlights structural connectors, not only busy stops. |
| Approximate harmonic centrality | Add a global accessibility centrality that works on disconnected graphs. | Closeness centrality, harmonic centrality, disconnected graphs. | Added sampled harmonic centrality using BFS from sampled source stops and summing inverse distances. | New output: `top_approx_harmonic_stops.csv` and `top_approx_harmonic_stops.png` after full rerun. |
| Bridges and articulation points | Find structurally fragile stops and edges. | Bridges, articulation points, graph cuts, connectivity. | Compute articulation points and bridges on the undirected graph. | Existing output found 900 articulation points and 971 bridges. |
| Louvain communities | Identify regional or functional transit modules. | Community detection, modularity, clustering. | Run Louvain community detection with edge frequency as weight. Export community sizes and top stop per community. | Existing output found 91 communities; largest has 1,260 stops. |
| Degree distribution | Study whether the graph is hub-dominated. | Degree distribution, heavy tails, scale-free discussion. | Added a degree distribution table and log-log plot. | New output: `degree_distribution.csv` and `degree_distribution_loglog.png` after full rerun. |
| Shortest-path network statistics | Estimate path length and graph diameter. | BFS, shortest paths, average path length, diameter. | Added sampled BFS from source stops in the largest component. | New fields in `network_summary.csv`: approximate average shortest path and approximate diameter after full rerun. |
| Resilience simulation | Test random vs targeted station failures. | Robustness, giant component, attack vs random failure. | Remove stops by centrality ranking and measure the largest remaining connected component. Compare to random removal. | Existing result: removing 500 articulation-ranked stops leaves 93.64% in the largest component, worse than random mean at 97.32%. |
| Accessibility damage | Measure passenger-style damage, not only component size. | Shortest paths, reachability, path stretch, robustness. | Added sampled origin-destination pairs. After removals, recompute reachability, average shortest path, stretch, and detour. | New output: `accessibility_damage_by_removal.csv` and `accessibility_damage_curve.png` after full rerun. |
| Network model comparison | Compare real transit structure to theoretical models. | Erdos-Renyi, configuration model, Barabasi-Albert, Watts-Strogatz, small-world networks. | Added generated reference graphs with comparable size/degree and compare clustering, components, path length, and density. | New output: `network_model_comparison.csv` and `network_model_comparison.png` after full rerun. |
| Small-world interpretation | Check if the transit graph has short paths plus high clustering. | Small-world model, clustering coefficient, path length. | Compare real approximate path length and clustering to ER and WS reference graphs. | Implemented in model comparison; final numeric conclusion requires full rerun. |
| Course-guideline compliance | Make the submission easier to defend. | Project instructions: reproducibility, algorithms, results, presentation, individual contributions. | Updated README outputs and guideline compliance notes. Added this summary report. | Repo now maps the work more directly to lecture themes and project requirements. |
